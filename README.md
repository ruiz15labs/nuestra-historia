# Nuestra Historia — V3

Esta versión mantiene el diseño móvil aprobado y conecta el material seleccionado con Cloudinary.

- Cloud name: `sicykhot`
- 67 fotos seleccionadas
- 49 videos MP4 seleccionados
- 1 imagen adicional encontrada en el archivo de videos
- `media.js` contiene las URLs de Cloudinary
- `index.html` contiene la historia y las secciones
- `style.css` contiene el diseño
- `script.js` genera la galería y los reproductores

## Cómo instalar en tu proyecto de VS Code

Copia/reemplaza estos archivos en tu carpeta actual:

- `index.html`
- `style.css`
- `script.js`
- `media.js`

Conserva `assets/hero.jpg`.

Después abre con Live Server como antes.

## Importante

No hace falta copiar manualmente las 117 URLs. Las URLs de Cloudinary ya están generadas en `media.js` a partir de los archivos seleccionados.

Si más adelante agregas nuevas fotos/videos a Cloudinary, actualizaremos `media.js` y la página sin cambiar el enlace principal.
